# Estructura Orgánica: Facultad o Dependencia UNALM *

Este documento consolida y desglosa la **estructura completa jerárquica (Padre - Hijos)** del campo **`Facultad o Dependencia UNALM *`** utilizado en el sistema de **Mesa de Ayuda UNALM** (portal de solicitantes, registro de usuarios, tickets de soporte y módulo administrativo).

---

## 1. Resumen Global de la Distribución

| Métrica / Dimensión | Cantidad | Descripción |
| :--- | :---: | :--- |
| **Órganos Padre (Categorías)** | **26** | Facultades, Rectorado, Vicerrectorados, Direcciones y Oficinas Centrales. |
| **Unidades Finales Registradas (Select)** | **117** | Total de opciones disponibles en el componente selector `SearchableDependenciaSelect`. |
| **Facultades Académicas** | **8** | Las 8 facultades históricas de la UNALM. |
| **Dependencias Desglosadas de Facultades** | **52** | Departamentos académicos, programas de investigación, granjas y centros. |
| **Dependencias Administrativas y Centrales** | **65** | Direcciones, oficinas centrales, plantas piloto, laboratorios e institutos. |
| **Áreas Operativas Internas (Soporte/SG)** | **+7** | Unidades especializadas registradas en base de datos para técnicos y resolutores. |

## 8. Arquitectura e Integración Técnica en el Sistema

1. **Persistencia en Base de Datos MySQL (`schema.sql`):**
   * Tabla `usuarios`: campo `facultad_dependencia VARCHAR(150) NOT NULL DEFAULT 'OTIC'`.
   * En tickets, las incidencias vinculan al solicitante y su facultad/dependencia para trazabilidad en reportes ITIL y órdenes de trabajo.
2. **Definición Estructurada Backend (`server/organos_data.json`):**
   * Archivo JSON estructurado en arreglos de objetos `{ "padre": string, "hijos": string[] }`.
   * Script generador `server/generate_structure.js` para compilar el dataset oficial al frontend.
3. **Consumo en Interfaz de Usuario Frontend:**
   * Archivo de datos: `client/src/data/unalmStructure.ts` (`UNALM_ORGANIGRAM_UNITS`).
   * Componente con buscador en tiempo real, agrupamiento por categorías e íconos temáticos: `client/src/components/SearchableDependenciaSelect.tsx`.
   * Vistas activas: Portal del Solicitante (`SolicitantPortal.tsx`), Login/Registro (`LoginPage.tsx`) y Gestión de Usuarios (`AdminUsersPage.tsx`).
